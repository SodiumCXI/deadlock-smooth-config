# Deadlock Smooth Config

Оптимизированный `gameinfo.gi` для Deadlock: меньше фризов и выше FPS. Геймплейно важное (прорисовка, лампы, обводки, способности, тени игроков) не тронуто.

## Установка

1. Закройте игру.
2. Скачайте `gameinfo.gi` из **[релиза](../../releases/latest)** и замените им `Steam\steamapps\common\Deadlock\game\citadel\gameinfo.gi`.

## Важно

- После обновления игры файл может перезаписаться, положите его заново.
- Вернуть оригинал: Steam -> Свойства -> Установленные файлы -> Проверить целостность.
- `r_aspectratio 2.3` растягивает картинку, удалите строку, если не нужно.

## Лицензия

`gameinfo.gi` основан на файле Valve. Лицензия MIT распространяется только на изменения. Проект не связан с Valve.
